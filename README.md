# Laya typed-decisions model pack

ONNX conversion of [convaiinnovations/laya-typed-decisions](https://huggingface.co/convaiinnovations/laya-typed-decisions), revision `1a793eb568e6718f15941d08f85432581df534e3`. Distributed under Apache-2.0; see LICENSE and NOTICE.

Includes CPU int8 and GPU fp16 models, tokenizer, configuration and golden validation cases. The manifest records conversion tools and weight checksums. No application source or user data is included.

Portable Coding Tool downloads and verifies these files automatically from Settings > System 1. The CPU runtime is included with the Windows installer; GPU acceleration is optional.
